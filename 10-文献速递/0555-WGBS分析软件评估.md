# WGBS分析软件评估

> 原文：https://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247504746&idx=1&sn=5ef7e3874dd8c2b41b601582ee7db022&chksm=9b3caa3aac4b232c344fbf25065363e7bf42a945fe878ee7fe524077b7ede09b806407dd46fd#rd
> 合集：文献速递

**一、写在前面**

DNA的甲基化水平(尤其是5-甲基胞嘧啶，5mC)与转录调控、基因组印记、干细胞分化、胚胎发育等息息相关。全基因组重亚硫酸盐测序(Whole-genome bisulfite sequencing, WGBS)能够高通量的捕获5-甲基胞嘧啶，这篇题为"Analysis and Performance Assessment of the Whole Genome Bisulfite Sequencing Data Workflow: Currently Available Tools and a Practical Guide to Advance DNA Methylation Studies."的综述，其目的为介绍当前广泛使用的WGBS分析软件，并给出了一个示例代码。于2022年发表于《small methods》上，**IF=12.4** ，干货满满，我们也会陆续出一些与WGBS分析相关的代码教程。大家可以先熟悉一下Linux环境：[Linux教程合辑](<https://mp.weixin.qq.com/mp/appmsgalbum?__biz=MzAwMzIzOTk5OQ==&action=getalbum&album_id=2545945566388977666&scene=173&from_msgid=2247500900&from_itemidx=1&count=3&nolastread=1#wechat_redirect>)。

**二、背景知识**

5mC在哺乳动物基因组中非常常见，且多出现在**CG位点** 上。在人类体细胞的基因组中，大约**70~80%** 的位点处于甲基化状态下。重亚硫酸盐能够将为经甲基化的胞**嘧啶C转化为尿嘧啶U** ，从而导致后续扩增时这一位点**被T替代** 。利用这一原理，WGBS能够高通量的捕获到基因组中的5mC。对于不同的文库制备方案与测序平台来说，它们的测序深度、测序质量、重复率、比对效率、甲基化水平评估都可能不同。而WGBS的分析是一个机器**耗费计算资源**(CPU)、内存、存储空间的过程([生信分析为什么要使用服务器？](<http://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247501099&idx=1&sn=78446147184292fad3417495926b3096&chksm=9b3cbc7bac4b356dcf0460781f9bf16df4ede481f8cc57282c7384b9d2baccaa820d64c89bab&scene=21#wechat_redirect>))。因此，一个用户友好型、稳定可重复、计算效率高的分析流程十分重要。因此作者整理了WGBS主流**建库策略** 与**分析软件** 的横向对比。这里我们仅讨论分析流程的内容，对建库策略及测序方案感兴趣的同学可以看一下原文**2~3页** 。WGBS的文章我们也分享过，感兴趣的同学可以先阅读一番，了解更多的背景知识：

**三、WGBS分析流程**

**1、质量评估** 为了保证后续输入的reads能够成功的比对到参考基因组，WGBS分析流程的第一步就是对fastq文件的质量评估，QC这一环节几乎没有争议，业内清一色用的都是**fastqc** ，它能够对fastq文件的Per base sequence quality、Per tile sequence quality、Per sequence quality scores、Per base sequence content、Per suquence GC content、Per base N content、Sequence Length Distribution、Sequence Duplication level、Adaptor Content这九个方面进行评估，并且生成容易阅读的html文件(Figure 2, Step1)。值得注意的是，WGBS数据中GC的含量通常偏低(未经甲基化的C被转换为了T)，这并不是由测序质量问题引起的。
**2、reads修剪** 在fastqc对fastq文件进行质量评估后，需要对低质量reads、接头序列、污染序列、重复序列进行去除(Figure 2, Step 2)，这一步成为修剪(Trimming)。这一步选择的软件也较少，公认**Trim Galore** 与**Trimmomatic** 较为优秀。其中Trim Galore能够自动识别技术序列(接头、引物等)，也就是说更适用于大家从数据库中拿到的，没有技术序列文件的数据。

**3、Alignment**
在普通的基因组重测序项目中比对(Alignment)步骤就很关键，在WGBS中更是核心步骤，在建库时只有5mC被保留，而未经甲基化的胞嘧啶已经被转换为T，这为**Alignment算法** 的设计带来了挑战。为了解决这种变化带来的reads与参考基因组不匹配的问题，有两种主要的策略：**三字符策略** 与**通配符策略** 。三字符策略是将基因组中的所有C转换为T，这样即可完成reads与基因组的比对。通配符策略是指将基因组中的C转换为Y，允许Y匹配C与T两种字符。相较于三字符策略，通配符策略能够达到**更高的基因组覆盖率但甲基化水平评估也会更高**(可以理解为假阳性)。其中三字符策略的代表软件为Bismark、BWA-METH，通配符策略的代表软件为BRAT_BW、BSMAP、GSnap。在众多Alignment软件中，作者推荐Bismark、BWA-METH、gemBS，这几款软件较其他软件而言能节省约1/3的运行时间且能良好的**平衡运行时间与比对质量** 间的关系。作者比对了常用的几款软件(Bismark、BitMapperBS、BWA-Meth、gemBS)在不同平台建库方案(EMSeq、MethylSeq、SPLAT、TrueMethyl、TruSeq)中的表现情况。在用相同的数据进行测试后，Bismark无论是在比对速率(Average runing time、Read pairs/sore/sec)还是在准确率(Standard deviation)上在四个软件中均较差(Table 1)，但其实Bismark还挺好用的。

**4、比对质量评估**
考虑到重亚硫酸盐的转化效率并**不是100%**(存在一部分未甲基化的C被保留)，且包含5mC的DNA片段在提取DNA及建库过程中更不易降解，因此Alignment得到的甲基化率是要**高于实际水平** 的，因此对于比对质量的评估和校验就显得十分重要。比对质量可以参考下面介绍的甲基化信息提取一起判断。
**5、甲基化信息提取**
在用BitMapperBS、BWA-Meth、Bismark、gemBS等比对工具后，作者推荐使用**MethylDackel** 提取甲基化信息。甲基化位点的评估基于比较测序reads相较于基因组多出来的"C"来实现。MethylDackel通过比对得到的BAM文件生成bedGraph文件，其中记录了甲基化与未甲基化位点的信息，可以用于下游**差异甲基化区域**(Different methylation region)的计算。

6、数据标准化与统计分析类似于我们在转录组中谈到过的那样([FPKM,TPM, Counts: 谁更适合做差异分析？](<http://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247496654&idx=1&sn=6b5953624fc3fed3798951b19b608349&chksm=9b3c8a9eac4b0388ee47f861401f78d0787f7b096b80ec5e966cb9812f4439fe70fd9a99ec57&scene=21#wechat_redirect>))，甲基化数据在进行组间差异计算时面对的问题也有需要因素需要考虑。首先，不同测序方法、样本得到的CpG位点数量会有出入，因此normalization的方式选择就极为重要，但WGBS分析中并没有如同RNA-Seq中那样广为认可的normalization方式。**CpG位点数量、reads数量、reads分布、覆盖度、比对准确度** 在normalization过程中均是需要考虑的点。这里作者推荐通过"BedGrap downsampling"来实现normalization的过程。

**7、DMR**
甲基化的分布几乎是一个**二项分布**(甲基化/未甲基化)，DMR的计算是WGBS分析的核心内容与目的，涉及到的算法与工具也比较多：
(1)、BSmooth: 在样本特异性的甲基化信息中利用**局部似然平滑法**(local likelihood smoothing approach)计算DMR。通过预设β值并利用Welch's t-test获得P值。但是这种策略会导致二类错误的产生(假阴性)。
(2)、BiSeq: 该工具通过**β二项分布模型** 充分考虑到了生物学重复，从而避免了二类错误的出现。并且BiSeq进一步通过triangular kernel model对显著性进行矫正，对P值进行标准化后生成Z-score。
(3)、MethylSig: 类似于BiSeq，这款软件亦是通过**β二项分布模型** 考虑reads分布以及生物学意义。
(4)、Metilence: 整合**二项分割与multivariate kolmogorov-smirnovgoodness-of-fit test** 。这种非参数方法逐步分割基因组区域进行计算从而增强了统计检验的显著性。因此这种算法对于累计样本差异性更为敏感。(5)、methylkit: 利用**Fisher's精确检验** 分析单样本间的差异分析，利用logistical回归分析计算多样本的组间差异。(6)、Defiant: 采用**Welch expansion** 识别DMR，其中利用**Fisher's精确检验** 分析单样本间的差异分析，利用Welch's t-test计算多样本组间的差异，并且通过覆盖率进行组间差异矫正，随后通过Benjamini-Hochberg方法对P值进行矫正。

**四、工具总结**

光说不练假把式，最后作者整理了目前常用的WGBS分软件的描述、网址、下载方式，我们后面的推送会挑选一些软件找个测试数据来run一番。
