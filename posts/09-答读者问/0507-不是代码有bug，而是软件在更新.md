# 不是代码有bug，而是软件在更新

> 原文：https://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247535577&idx=1&sn=d38e5da6971ad77d0b5cb83a7026f2c6&chksm=9b3c3289ac4bbb9f5b334cbd082850b69a54b9c1f4b19dd5130c306ce6a1382d087c8000b8f7#rd
> 合集：答读者问

有些流程，跑着跑着就不一定能用了，例如做单细胞分析时常有这么两行用来计算所有cluster的top marker gene。

  *   *   *   *   *

```r
scRNA.markers <- FindAllMarkers(scRNA, only.pos = TRUE, min.pct = 0.25, logfc.threshold = 0.25)
 top10 <- scRNA.markers %>% group_by(cluster) %>%  top_n(n = 10, wt = avg_logFC)
```

遇到了如下报错：![](https://mmbiz.qpic.cn/mmbiz_png/ImlBFVOwwpxINRVLpmPpicPMEevIpvmEZNVVuQDrccRlsZuPuxwL4EDpHynSp2lVoWo4PadjZO06ZOQoOztAJSg/640?wx_fmt=png&from=appmsg)其实原因也很简单：Seurat更新了，FindAllMarkers()函数输出的数据框中保存"基因差异倍数对数值"的列名由avg_logFC改为了avg_log2FC。做对应修改即可：

  *   *

```r
top10 <- scRNA.markers %>% group_by(cluster) %>%   top_n(n = 10, wt = avg_log2FC)
```
