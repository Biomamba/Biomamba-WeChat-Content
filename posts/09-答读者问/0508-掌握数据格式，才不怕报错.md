**二、有问题就有答案**

显然这不能怪10X和华大，更不能怪Seurat，每个平台有自己输出文件的习惯很正常，此前我们演示过[华大C4平台scRNA-seq定量分析](<https://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247533649&idx=1&sn=1cbe6e3116527a14c239f4e6fa2ab553&scene=21#wechat_redirect>)流程，输出的features.tsv.gz文件中只包含了一列Gene的Symbol，而10X的genes.tsv第一列是ENS编号，第二列才是基因Symbol：![](../../images/a026f9b41193d749.png)
![](../../images/a947a3560238b473.png)但Read10X()默认读取第二列作为gene名，显然，你不能读取一个不存在的列：![](../../images/2bcdfdec598526bc.png)
这是个古老的问题([答读者问（八）为什么Read10X也会报错?](<https://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247485012&idx=1&sn=6007c8d7cb2a236dd7240a678dac0391&scene=21#wechat_redirect>))，所以这位同学遇到的报错只需要在Read10X()函数中设置一下gene.column=1即可。一个简单的问题落在小白的身上就是一座山([突然想起学单细胞走过的弯路](<https://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247533491&idx=1&sn=1dd2fe09639fcb52ac5be6d2af2b77b6&scene=21#wechat_redirect>))![](../../images/e28e3c7864dbd762.webp)事实上如果你对R语言和单细胞足够了解，你完全可以不用Read10X()函数：

  *   *   *   *   *   *

```r
# 加载包：library(Matrix)# 读取填充值：mymatrix <- readMM(gzfile('matrix.mtx.gz'))# 转换为dgC矩阵mymatrix <- as(mymatrix,'dgCMatrix')
```

  *   *   *

```r
# 读取基因：feature <- read.table(gzfile('features.tsv.gz'))feature <- feature[,1]# SYMBOL在第二列就写2
```

  *   *   *

```r
# 读取barcodebarcodes <- read.table(gzfile('barcodes.tsv.gz'))barcodes <- barcodes[,1]# barcode在第几列就填几
```

  *   *   *   *

```r
# 合并矩阵并创建Seurat对象rownames(mymatrix) <- feature # 行名为基因名colnames(mymatrix) <- barcodes scRNA <- Seurat::CreateSeuratObject(mymatrix)
```
