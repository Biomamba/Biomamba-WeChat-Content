**二、有问题就有答案，详解稀疏性**

##  1、何为稀疏性

单细胞测序技术中的稀疏性是指在表达矩阵中，大量元素为**0** 的现象。稀疏性的量化方式通常为：稀疏度 = (矩阵中 0 的数量)/(矩阵总元素数量)。实际分析中，单细胞矩阵的稀疏度往往高达90%+（即绝大多数基因在绝大多数细胞中**检测不到** 表达），而 bulk RNA-seq 矩阵的稀疏度通常低于 50%，二者差异显著。

## 2、稀疏的锅给谁背

单细胞数据的高稀疏性并非随机产生，而是由技术限制和生物学特性共同导致：

### (1)生物学因素

  * 基因表达的细胞特异性：
多数基因仅在特定细胞类型或状态中表达（如免疫细胞的细胞因子基因仅在激活时表达），在其他细胞中自然为 0。
  * 转录本的低丰度：
许多基因（如调控基因）在细胞中的表达量极低，仅少数分子甚至不表达，导致计数为 0。
  * 细胞周期或瞬时状态：
基因表达随细胞周期或动态过程（如分化）呈现瞬时性，某一时刻的检测可能恰好捕捉到 “不表达” 的状态。

### (2)技术因素

  * 扩增偏差：
单细胞测序需对微量RNA（通常每个细胞仅1-10pg）进行扩增，低丰度转录本可能因扩增效率低而丢失，最终表现为0。
  * 捕获效率低：
单细胞捕获过程中，RNA分子可能未被有效捕获（如液滴法中细胞与磁珠结合失败），导致基因计数为0。
  * 测序深度不足：
为降低成本，单细胞测序的测序深度通常远低于bulk测序（如每个细胞50k-1M reads，而Bulk通常能获得100M reads/样本），低丰度基因可能未被测序覆盖，表现为0。

## 3、稀疏性对数据分析的影响

### (1)、数据存储与计算(算是优点)

高稀疏矩阵若用常规稠密矩阵存储（如 R 中的matrix），会占用大量内存（例如 10 万个细胞 ×3 万个基因的矩阵，**稠密** 存储(如矩阵、数据框)需约12GB，而稀疏存储仅需数百 MB）。因此，单细胞工具通常采用稀疏矩阵格式（如 R 中的dgCMatrix、Python 中的scipy.sparse）优化存储和计算效率。

### (2)、下游分析偏差

  * 聚类与分群：
稀疏性可能掩盖细胞间的真实差异，例如低表达基因的 0 值可能被误判为 “不表达”，导致相似细胞被错误分组。
  * 差异表达分析：
0 值的大量存在会影响统计模型的假设（如正态分布），需使用针对稀疏数据的方法（如 MAST、DESeq2 的单细胞适配版本）。
  * 降维与可视化：
主成分分析（PCA）、t-SNE 等方法对 0 值敏感，直接分析可能导致维度偏差，需先通过标准化（如 log 转换加伪计数）或插补（imputation）处理。
  * 生物学解读误区
无法区分 “真 0”（基因确实不表达）和 “假 0”（技术原因导致的表达缺失），可能误判基因的细胞特异性。

## 4、稀疏性的处理策略

### (1)数据预处理优化

  * 过滤低质量细胞和低表达基因：
移除检测基因数过少的细胞（可能因捕获失败导致大量 0）和在极少数细胞中表达的基因，减少无效0值。
  * 标准化与伪计数：
对表达量加一个小的伪计数（如 1）后再进行 log 转换，避免 0 值对后续计算的干扰（如避免 log (0) 的无穷大问题）。
  * 插补（Imputation）方法
基于统计模型推测 0 值的可能表达量，如利用相似细胞（如同一聚类）的基因表达模式填补（代表工具：MAGIC、kNN-smoothing、SAVER）。但需注意：插补可能引入假阳性信号，需谨慎验证。

### (2)针对性算法设计

许多单细胞分析工具已内置对稀疏性的适配，例如： **聚类算法** ：`Louvain`、`Leiden`算法对稀疏矩阵的处理效率更高；
**降维工具** ：`UMAP`、`t-SNE`通过优化距离计算减轻0值影响；
**差异分析** ：`MAST`模型直接纳入0值的统计分布（假设表达量服从零膨胀负二项分布）。

## 2、可以，但没必要

`Seurat`的流程中并没有`FPKM`的计算过程，Seurat的标准化逻辑很简单：

### (1)、对每个细胞的所有基因计数进行缩放，使它们具有相同的 “虚拟测序深度”。

  *

```
归一化计数 = (原始计数 / 该细胞总计数) × 缩放因子(scale.factor)
```

### (2)、对数化

公式为：

  *

```
最终值 = log(归一化计数 + 1)
```

  * 为什么加1（即 log1p）：
避免对0取对数（单细胞数据中大量存在），同时保留0值的生物学意义（基因未表达）。

  * 为什么取对数：
压缩高表达基因的动态范围，使数据更符合正态分布，便于下游分析（如聚类、降维）。 放大低表达基因的差异（这些基因往往更具生物学意义，如转录因子）。 使表达量的倍数变化（如 2 倍差异）在对数空间中表现为线性差异（如 log2 ≈ 0.69）。

### (3) 实际操作
