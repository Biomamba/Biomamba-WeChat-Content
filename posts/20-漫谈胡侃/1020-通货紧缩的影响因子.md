# 通货紧缩的影响因子

> 原文：https://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247519764&idx=1&sn=ebefd61a929b25b6f0234fe067a819ce&chksm=9b3cf744ac4b7e52ed826209b11f6ce5096400f9f06d54fc4426d509dfd256e72c17df6a0675#rd
> 合集：漫谈胡侃

新一年的影响因子(Impact Factor, IF)前几周公布了。IF是由 _Clarivate_ 的Journal Citation Reports(也就是大家熟知的JCR: https://jcr.clarivate.com/jcr/home)发布的期刊评价指标，目前来说是衡量一个期刊质量的首要可量化标准，其计算公式为该期刊第三年的被引用数/前两年的发文数。也就是说今年(2024)发布的2023影响因子=23年被引用数/(2021年发文量+2022年发文量)，基本上可以反应一个期刊三年内的热度。而大家今年中的文章，**评奖** 、**毕业** 时参考的也就是昨天发布的这个数值，值得一提的是，大部分期刊的影响因子在2024年6月公布的。网传了几个影响因子数据表，我们来稍微探索一下：

# 有没有哪个杂志的影响因子是上升的呢
```r
# 由于数据集来源于互联网，可能有一些期刊名不统一，我们取出2022和2023年度中都有IF收录的期刊：
journal_list <- intersect(filter(JCR,Year==2023) %>% pull(Journal) %>%   unique(.),
filter(JCR,Year==2022) %>% pull(Journal) %>%   unique(.))
increase_data <- data.frame()
for (run_journal in journal_list) { # 取出有2023影响因子记录的期刊名参与循环
  temp_JCR <- filter(JCR,Journal == run_journal)
  IF_2022 <- filter(temp_JCR,Year==2022) %>% pull(IF)
  IF_2023 <- filter(temp_JCR,Year==2023) %>% pull(IF)
  if (IF_2023 > IF_2022) {
    increase_data <- rbind(increase_data, c(run_journal,IF_2023,IF_2022) )
  }
}

colnames(increase_data) <- c('name','IF_2023','IF_2022')

head(increase_data)
```
