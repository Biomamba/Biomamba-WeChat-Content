# 看了两万多篇期刊,居然有影响因子是0的?(文末附完整表格)

> 原文：https://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247488311&idx=1&sn=7267726ca19ed58705ff60e5d6b48021&chksm=9b3f6a67ac48e3710edc5bb2c37eac6884062f3126216cbb623273a74ec9884d31dff6f7009e#rd
> 合集：漫谈胡侃

昨儿发生了件大事，新一年的影响因子(Impact Factor, IF)公布了。IF是由 _Clarivate_ 的Journal Citation Reports(也就是大家熟知的JCR: https://jcr.clarivate.com/jcr/home)发布的期刊评价指标，目前来说是衡量一个期刊质量的**首要** 可量化标准，其计算公式为该期刊第三年的被引用数/前两年的发文数。也就是说今年(2022)发布的2021影响因子=21年被引用数/(19年发文量+20年发文量)，基本上可以反应一个期刊三年内的**热度。** 而大家今年中的文章，**评奖** 、**毕业** 时参考的也就是昨天发布的这个数值，我这有张汇总的表格，我们来看看今年新鲜的影响因子都有哪些要素。
```r
library(dplyr)
IF.2022.6 <- as.data.frame(readxl::read_xlsx('2022.xlsx'))
names(IF.2022.6)#看一下这个表包含了哪些信息
```
```
## [1] "journal_name"     "issn"             "eissn"            "category"
## [5] "citations"        "if_2022"          "jci"              "percentageOAGold"
```
```r
IF.2022.6$if_2022 <- as.numeric(IF.2022.6$if_2022)
summary(IF.2022.6$if_2022)
```
```
##    Min. 1st Qu.  Median    Mean 3rd Qu.    Max.    NA's
##   0.000   1.480   2.627   3.908   4.349 286.130    9006
```

所有期刊平均值是3.9、中位数是2.6，没达到这个标准的想想自己有没有在**灌水。** 最高的仍然是神刊**CA** ，虽然跟去年相比直接**腰斩** ，但是基本也比第二名多出一个**《Nature》**(IF=69.50)：
```
IF.2022.6 %>% top_n(n=5,wt = as.numeric(if_2022)) %>% .[,c(1,6)]
```
```
##                                       journal_name if_2022
## 1               CA-A CANCER JOURNAL FOR CLINICIANS 286.130
## 2                                           LANCET 202.731
## 3                  NEW ENGLAND JOURNAL OF MEDICINE 176.079
## 4 JAMA-JOURNAL OF THE AMERICAN MEDICAL ASSOCIATION 157.335
## 5            NATURE REVIEWS MOLECULAR CELL BIOLOGY 113.915
```

更喜闻乐见的是，居然有几个期刊是**零分** 的，让我们来看看到底是哪几个倒霉蛋
```
IF.2022.6 %>% filter(as.numeric(if_2022)==0) %>% .[,1]
```
```
## [1] "Sintagma"                          "BMC Biophysics"
## [3] "WOCHENBLATT FUR PAPIERFABRIKATION" "LIBRARY AND INFORMATION SCIENCE"
## [5] "SECURITIES REGULATION LAW JOURNAL" "BELL LABS TECHNICAL JOURNAL"
```

我本以为是哪个**新期刊** 当了倒霉蛋，但是仔细思考一下新期刊应该是NA才最，检索一番(比如这个**Sintagma**)，发现这并不是个新刊，讲道理2018年之际影响因子还高达**0.5** ，没想到今年跌了个底儿掉

![](https://mmbiz.qpic.cn/mmbiz_png/ImlBFVOwwpyar0wQVwPW1QGmuMqw0Oc63jZR49bSRZ94D8hyzzGgKJhuHm7dDOdE0UaDzxNhrkgPwCZTSBficeA/640?wx_fmt=png)

而**BMC Biophysics** 在去年公布的2020年影响因子还是高达**4.78** ，这就是一个很诡异的事情，仔细搜了一下，这个杂志发文一直较少，近两年直接就停刊了:那明年这文章影响因子不得无穷大？言归正传，这也提醒大家当年影响因子并不是选择杂志的最重要因素，杂志的发文量、前几年的影响因子稳定性同样需要重点观察。
