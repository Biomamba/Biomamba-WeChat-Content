GPU使用协议

为了让大家都能健康、高效的使用GPU，大家需要遵守以下协议哦：

在使用本服务前，您需承诺遵守本协议的所有规定。

一、服务内容

西柚云提供GPU共享服务器服务，所有已购买指定套餐的用户可通过该服务利用共享的GPU资源进行合法的计算任务。由于CPU特惠版与专业版的GPU资源为免费使用的，目前上架GPU数量有限，为避免资源的长时间占用，入门版GPU节点的使用采用排队机制分配。GPU特惠版、GPU进阶版、GPU专业版用户无需排队使用。

  1. 如果您是3.0特惠版、3.0专业版用户，有GPU使用需求，请联系客服提交排队申请。您可按照以下教程安装GPU驱动。

                • *
# 添加NVIDIA官方仓库add-apt-repository -y ppa:graphics-drivers/ppaapt update
# 安装最新稳定版驱动（根据实际情况调整版本号）apt install -y nvidia-driver-535
# 安装CUDA工具包（可选，用于深度学习）apt install -y cuda-toolkit-12-1

当排队轮到您时，相关工作人员将开启服务器GPU的使用权限并进行相关通知，时间结束后，相关工作人员将关闭服务器GPU使用权限。

  1. 系统会根据用户请求的先后顺序以及任务优先级进行资源分配。在排队期间，请您耐心等待，我们会尽力优化资源调度，缩短您的等待时间。

二、资源协调

  1. 为确保所有用户都能公平使用GPU资源，我们会实时监控资源使用情况，并根据实际情况进行动态调整。

  2. 若您的任务对资源需求较大或持续时间较长，建议您提前与我们沟通，以便我们更好地协调资源，保障服务的顺畅运行。

三、用户使用行为规范

为保障服务器稳定运行以及其它用户的使用体验，以下行为均为禁止行为。

  1. 严禁运行加密货币挖矿、区块链计算等高功耗任务，此类操作将触发实时资源监控警报并立即封禁账号。

  2. 严禁大型AI模型训练（如千亿参数级模型训练、分布式训练集群），不能部署olama等应用。

  3. 单任务最长运行时间≤72小时，超时任务将被强制终止（特殊需求需提前申请）。

  4. 禁用未授权软件与系统操作。

  5. 禁止扫描端口、渗透测试、DDoS攻击等危害网络安全的行为。

四、监控与违规处理

实时监控策略

系统自动检测以下行为并告警：

  1. 持续满负载运行＞24小时（疑似挖矿/训练）

  2. 非常规端口通信

  3. CUDA进程异常多开

违规处罚

  1. 不承诺资源可用性：因维护、硬件故障导致的服务中断不承担责任。

  2. 数据自担风险：用户需自行备份数据，服务器不提供灾难恢复服务。

  3. 法律连带责任：用户因违规操作（如：黑客攻击）导致的法律问题需自行承担，服务方保留追偿权。
