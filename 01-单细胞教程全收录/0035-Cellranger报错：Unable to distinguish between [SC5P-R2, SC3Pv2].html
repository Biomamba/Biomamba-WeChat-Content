写在前面

之前处理了一个10X数据[1]的cellranger遇到一点小报错，大家可以参考下面的解决方案。 cellranger快速上手教程可参考：单细胞分析的最上游——处理Fastq文件：cellranger计算资源可参考：有root权限的共享服务器当然，如果需要cellranger定量服务也可以联系文末微信。

报错及解决方案

运行：

        • *
cellranger count --id=EP-07-B-10xT \                   --transcriptome=~/refdata-gex-GRCh38-2020-A/ \                   --fastqs=~/ascp_single/fastq/41967020-B-T_0_1_CCTLEANXX/ \                   --sample=bamtofastq \                   --nosecondary

有如下报错：

                                    • *
Unable to distinguish between [SC5P-R2, SC3Pv2] chemistries based on the R2 read mapping for Sample bamtofastq in "~/ascp_single/fastq/41967020-B-T_0_1_CCTLEANXX".Total Reads          = 100000Mapped reads         = 96403Sense reads          = 1Antisense reads      = 1
In order to distinguish between the 3' vs 5' assay configuration the following conditions need to be satisfied:- A minimum of 1000 confidently mapped reads- A minimum of 5.0% of the total reads considered needs to be confidently mapped- The number of sense reads need to be at least 2x compared to the antisense reads or vice versa
Please validate the inputs and/or specify the chemistry via the --chemistry argument.

Waiting 6 seconds for UI to do final refresh.Pipestance failed. Use --noexit option to keep UI running after failure.
2023-08-01 03:09:03 Shutting down.Saving pipestance info to "EP-07-B-10xT/EP-07-B-10xT.mri.tgz"

这个报错是由于 cellranger count 命令未能根据R2读取的映射结果准确地区分两种可能的chemistry版本（SC5P-R2 和 SC3Pv2）。cellranger 运行时满足以下条件之一，才能准确地区分两种可能的chemistry：至少1000个有置信度的映射读取 (confidently mapped reads)、至少总读取数的5.0%需要是有置信度的映射读取、正义链读取数或反义链读取数至少是另一条链读取数的2倍。在这种情况下，映射到基因组的读取数是96,403，少于1000，所以第一个条件不满足。另外，正义链和反义链的读取数都是1，远小于另一条链的2倍，因此第三个条件也不满足，软件无法自动识别chemistry。解决此问题的方法是通过 --chemistry 参数明确人工指定(需要先确保输入文件和目录路径正确无误)： 最终运行代码：

          • *
nohup cellranger count --id=EP-07-B-10xT \                   --transcriptome=~biosoft/refdata-gex-GRCh38-2020-A/ \                   --fastqs=~/ascp_single/fastq/41967020-B-T_0_1_CCTLEANXX/ \                   --sample=bamtofastq \                   --nosecondary \                   --chemistry=SC5P-R2 &

当然，如果你的数据并不是来源于10X Genomics的任何版本，那么也会出现文章开头的报错。
