### 五角星通用画法（角尖方向是灵魂）

外接圆上取五个等距点，**隔点相连** （pentagram {5/2}）即得五角星；`theta` 控制角尖朝向——大星恒为 90°（正上），小星恒为“指向大星中心”。
```python
def star_vertices(cx, cy, r, theta_deg):
    ang = np.deg2rad(theta_deg) + np.arange(5) * (2 * np.pi / 5)
    pts = np.column_stack([cx + r * np.cos(ang), cy + r * np.sin(ang)])
    return pts[[0, 2, 4, 1, 3]]          # 隔点相连；pts[0] 即角尖

def star_heading_to(center, target):
    dx, dy = target[0] - center[0], target[1] - center[1]
    return float(np.degrees(np.arctan2(dy, dx)))   # 小星角尖方向
```

![五角星构造三步：五等分点、隔点相连、填充](../../images/7cf9d84f5f00a3e2.webp)▲ `star_vertices()` 的三步构造（大星 θ = 90°）![四颗小星角尖正对大星中心的角度示意](../../images/4c4d89d5352d6e0b.webp)▲ `star_heading_to()` 的效果：四颗小星角尖 θ = −149.04° / −171.87° / 164.05° / 141.34°，白点均落在“小星圆心 → 大星中心”连线上
