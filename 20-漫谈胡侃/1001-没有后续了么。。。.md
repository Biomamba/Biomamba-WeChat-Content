# 没有后续了么。。。

> 原文：https://mp.weixin.qq.com/s?__biz=MzAwMzIzOTk5OQ==&mid=2247505219&idx=2&sn=1d1a44d43c0b628d1e1b5576afb47bfa&chksm=9b3cac13ac4b25057411f011f8f286a162f35f57e8d9630028d0999c36dbb66b976107aacb3e#rd
> 合集：漫谈胡侃

**例题** ：

**假设** 有一个不法分子，研发出了一种致癌剂，毒害我们的同胞，不幸接触致癌剂的人员有**200名** ，分别有**三人** 不幸确诊(2020年我们的癌症新发情况约为457万人[1])。请用**R语言** 来回答：试问该致癌剂的接触是否导致这200名受害者患病比例高于总体人群？

**解** ：
```r
# 数量型的输入：在200人中，3个人患有疾病
paitient <- 3 #患病人数
student <- 200 # 受试人群

# 总体的患病率
toltal_p <- 4570000/1400000000

# 进行二项检验：是否观察到的患病次数高于期望的次数
test <- binom.test(paitient, student, toltal_p, alternative = "greater")# 题干问是否高于，因此做单边检验

# 输出检验结果
print(test)
```
```

##  0.004100613 1.000000000
## sample estimates:
## probability of success

```

**推断** ：结果中p=0.028，因此拒绝零假设，接受备择假设，该致癌剂的接触**的确** 导致这200名受害者患病比例大于总体人群。
